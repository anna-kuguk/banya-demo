# banya-demo

Демо-макет онлайн-брони «Шикши» - тот, что показывали до запуска настоящей брони.

**С 2026-08-14 главная страница репозитория (`index.html`) - редирект на живую
бронь в CRM: https://dev.banyakrp.ru/book/**

Почему так: макет выдавал гостю выдуманный номер брони «ШК-NNNN» и обещал
сообщение в мессенджер и чек на почту. В CRM такой брони не заводилось. Пока
старые ссылки из переписок и постов вели сюда, мы обещали то, чего не будет.

- `index.html` - страница-редирект. Переносит `utm`-метки из адреса, чтобы не
  терять источник гостя. Счётчика Метрики на ней нет: считаем настоящую бронь.
- `mockup.html` - сам макет, как был. Не выбрасываем (решение Ани): открывается
  по прямому адресу https://anna-kuguk.github.io/banya-demo/mockup.html

Настоящая страница брони живёт в репозитории `anna-kuguk/shiksha-crm`,
план - `plans/2026-08-12-onlain-bron-gostya.md`, Фаза 6.
